# Trail Tracer Mower

Firmware for the Trail Tracer Rx board on the mower.

**Install firmware in your browser:** https://rctestflight.github.io/Trail_Tracer_Mower/ (Chrome or Edge on a computer, Rx board on USB).

- Branches: `main` stable, `dev` development, tags `vX.Y.Z` releases.
- Quick start: [docs/quick_start.md](https://github.com/rctestflight/Trail_Tracer_Mower/blob/dev/docs/quick_start.md) on `dev`.

## This branch (dev-tyler)

Rx test build: ESP32 firmware 0.6.17 (environment `lolin_s2_mini`) with the Rx STM32 app 2.1.222 update pair in `stm32/`. `programmer.json` names the build for the browser programmer.
