Trail Tracer Rx programmer

Chrome or Edge, on the PC with the Rx on USB
  1. Plug an Rx into this PC.
  2. Press "Connect an Rx".
  3. Choose the Rx in the browser list.

After each restart or replug of the board, do steps 2 and 3 again. The Rx has no USB serial number, so the browser forgets it.
